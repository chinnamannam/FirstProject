# AddressBook

This is AddressBook Application Written in **C Language**.

## features
1. Add Student Details
2. Display Student Details
3. Update the Student Details
4. Delate the Student Details
5. No of Student in AddressBook
6. Display Specific Student Information.

## Requirements
1. **GCC Compiler** (Tested with GCC 13.3.0  on ubunt 24.04.1 WSL)
2. **Visual Studio Code** (for editing and running inside WSL)

## How Run
1. clone the Repo : git clone -b AddressBook https://github.com/chinnamannam/FirstProject.git
2. Open project inside VisualStudiocode
3. Inside WSL Terminal, Compile Project
4. gcc ./main.c
4. ./a.out
